# Freelancer Mod Studio

Freelancer data and system editing tools, maintained in the Groshlancer fork.

- [Repository](https://github.com/Groshyr/Freelancer-Mod-Studio)
- [Releases](https://github.com/Groshyr/Freelancer-Mod-Studio/releases)
- [Original upstream](https://github.com/DomGries/FreelancerModStudio)

The local checkout may remain named `FL Mod Studio`. Executable names, project
names, namespaces and release asset filenames retain `FreelancerModStudio` for
compatibility; the product name is **Freelancer Mod Studio**.

`updates.txt` provides the published installer version and download URL. The
application's update-manifest and release links and the installer publisher links
point to this fork. Repository renaming alone does not change release versions
or rebuild existing installers.
